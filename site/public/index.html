Apple ID 的账单
放进一个窗口

批量导入、会话检测、账单读写、出口切换，全部在本机跑完。

macOS Apple 芯片 · 39 MB Windows x64 · 24 MB

功能

批量导入
一行一个账号，导入前逐行校验格式并指出问题行。
会话检测
逐个探测会话是否还能作答，掉线立刻标出来。
账单读写
读取、修改、移除付款方式，保存后按服务端实际结果回显。
粘贴识别
地址和卡号文本直接粘进来，自动拆成表单字段。
出口切换
直连、固定代理、本机客户端、内置 mihomo，四种模式互斥。
本地留存
账号、会话、设置都躺在应用数据目录，不经过第三方。

安装

macOS

安装包没有公证，首次会被拦住。右键打开，或者执行下面这行：

xattr -dr com.apple.quarantine /Applications/Butter.app

Windows

SmartScreen 会提示未知发布者，点「更多信息」，再点「仍要运行」。

未激活可以用 2 个账号，激活后不限。

Butter 本地运行，不上传账号数据
