Butter

Apple ID 与商店账单，一个窗口管完

批量导入账号、检查会话、读取和修改账单、切代理线路。本地运行，数据留在这台机器上。

macOS Apple Silicon · DMG · 39 MB Windows x64 · 安装包 · 24 MB

v0.1.23

第一次打开

  • macOS：安装包没有公证，右键 → 打开，或执行 xattr -dr com.apple.quarantine /Applications/Butter.app
  • Windows：SmartScreen 选「更多信息 → 仍要运行」
  • 未激活可用 2 个账号，激活后不限

功能

  • 批量导入、批量登录、会话检测，进度实时可见
  • 读取、修改、移除商店账单，保存后按服务端实际结果回显
  • 直连 / 固定代理 / 本机代理 / 内置 mihomo 四种出口
  • 粘贴识别账单文本，自动填表
